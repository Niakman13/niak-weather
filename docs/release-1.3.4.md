# Niak Weather v1.3.4

Le halo de la synthèse est désormais plus large et diffus, avec une lumière moins concentrée autour de l’icône.

Dans la jauge du ressenti, le rond représente le ressenti calculé et le trait vertical représente séparément la température réelle mesurée.

Dans **HACS → Niak Weather**, mettez à jour vers **v1.3.4**, puis rechargez le navigateur avec **Ctrl+F5**.
