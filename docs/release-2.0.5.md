# Niak Weather v2.0.5 — une frise plus complète

- La frise montre tous les événements des prochaines heures, chacun à son heure : pluie, orage, gel, brouillard, température, pluie de demain.
- Air et pollens sur la frise dès 3 sur 6.
- Titre « Événements » au-dessus de la frise.
- Les événements proches dans le temps partagent une étiquette ; sur téléphone, les étiquettes ne gardent que leurs icônes.
- La vigilance n’est plus répétée sur la frise : sa pastille suffit.
- Nouveau réglage : couper l’effet verre dépoli sur un appareil lent.
- À installer avec l’intégration Niak Weather 2.0.5.
