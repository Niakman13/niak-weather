# Niak Weather v2.0.7-beta.5 — trois sections claires

- Carte complète : trois sections, toujours dans le même ordre, chacune avec son propre contenu.
- Bandeau intelligent : bulletin, événements, prochains moments, prévisions en tuiles. Il reste toujours, avec son ciel animé.
- Aujourd’hui : pluie, vent, pression, ressenti, pastilles, air et pollens du jour.
- Prévisions : les 18 prochaines heures, les 7 prochains jours, air et pollens de demain.
- Une section vide disparaît. Les réglages des bêtas précédentes sont repris automatiquement.
