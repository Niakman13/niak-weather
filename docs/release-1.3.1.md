# Niak Weather v1.3.1

L’indicateur « À surveiller » et les autres niveaux d’attention sont désormais alignés avec le titre principal de la synthèse, dans une bulle arrondie teintée selon le niveau d’attention. Les libellés « Environnement », « À venir », « Maintenant » et « Vigilance » reprennent ce style pour faciliter la lecture du brief. Sur les petits écrans, les bulles s’adaptent à la place disponible.

Dans **HACS → Niak Weather**, mettez à jour vers **v1.3.1**, puis rechargez le navigateur. Vos réglages sont conservés.
