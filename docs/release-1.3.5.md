# Niak Weather v1.3.5

Le halo de la synthèse est plus étendu et légèrement plus visible. Le bouton « À surveiller » est placé sous le titre de vigilance.

Dans la jauge du ressenti, le rond indique le ressenti et le trait vertical séparé indique la température réelle mesurée.

Dans **HACS → Niak Weather**, mettez à jour vers **v1.3.5**, puis rechargez le navigateur avec **Ctrl+F5**.
