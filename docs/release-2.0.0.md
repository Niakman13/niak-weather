# Niak Weather v2.0.0 — un cerveau et un écran

- La carte s’appuie désormais sur l’intégration Niak Weather, à installer aussi : c’est elle qui fait tous les calculs.
- Les sources se règlent dans l’intégration, qui reprend les réglages de vos cartes.
- Nouveau bandeau : vigilance en pastille, bulletin du jour rédigé comme une prévision, frise des heures à venir.
- Les alertes à leur heure sur la frise ; ce qui se passe maintenant réuni dans une seule étiquette.
- Ciel plus vivant : grand soleil, lune à cratères, neige qui tient au sol, grêle qui rebondit, pluie qui éclabousse.
- Onze capteurs pour vos automatisations, fournis par l’intégration.
- Carte deux fois plus légère.
- [Passer de la 1.20 à la 2.0](https://github.com/Niakman13/niak-weather/blob/main/docs/migration.md).
